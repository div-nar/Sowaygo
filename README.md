# Sowaygo

**Open-source Strava for bikes.** Track your rides, share your routes, and explore where the road takes you — built in the open, owned by no one.

> ⚠️ Early days. This is a fresh project and everything below is a starting point. Contributions, ideas, and issues are welcome.

## Vision

Sowaygo is a community-owned platform for cyclists to record, analyze, and share their rides. Think of the features you love in Strava — GPS ride tracking, segments and leaderboards, activity feeds, kudos, route planning — but fully open-source, self-hostable, and free from lock-in.

## Goals

- 🚴 **Ride tracking** — record rides via GPS (mobile) or import GPX/FIT files.
- 🗺️ **Routes & segments** — plan routes and compete on community-defined segments.
- 📊 **Stats & analysis** — distance, elevation, pace, power, and personal records.
- 👥 **Social** — follow other riders, share activities, give kudos and comments.
- 🔓 **Open by default** — no proprietary lock-in, self-hostable, MIT-licensed.

## Status

Just getting started. There's no code yet — the first milestones are:

1. Decide on the tech stack (backend, mobile, web).
2. Define the core data model (users, rides, tracks, segments).
3. Ship a minimal ride-recording + upload flow.

If you'd like to help shape any of these, open an issue to start the conversation.
